Technical Architecture & Implementation Details

Core components configured according to the project specification

🔐 Spring Security & RBAC

Stateless token architecture with JwtAuthenticationFilter, BCrypt password hashing, method-level @PreAuthorize annotations, and HTTP 401/403 handlers.

🌐 RESTful CRUD API

Standardized JSON responses, HTTP status codes (200 OK, 201 Created, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found), and field validation.

🐳 Docker & Compose

Production multi-stage Dockerfile (Temurin 21) and compose.yaml containerizing Spring Boot and PostgreSQL with automated healthcheck networking.
